🛡️ FDIA Medical Security System
🔹 Overview

The FDIA Medical Security System is a cybersecurity-driven application designed to detect False Data Injection Attacks (FDIA) in medical systems. It combines machine learning with explainable AI to ensure the integrity of healthcare data.

🔹 Live Demo

📌 Application Link

https://fdia-medical-security-system.onrender.com/login

📌 GitHub Repository

https://github.com/shanmugamani45/FDIA-Medical-Security-System
🔹 Problem Statement

Modern healthcare systems depend on accurate data. FDIA attacks can:

⚠️ Corrupt patient records
⚠️ Lead to incorrect diagnoses
⚠️ Compromise critical decision-making

🔹 Installation & Setup
📦 Clone Repository
git clone https://github.com/shanmugamani45/FDIA-Medical-Security-System.git
cd FDIA-Medical-Security-System
🧪 Create Virtual Environment
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
📥 Install Dependencies
pip install -r requirements.txt
▶️ Run Application
python app.py
🌐 Open in Browser
http://localhost:5000
